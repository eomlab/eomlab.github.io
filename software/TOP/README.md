# TOP — The Optothermal Photonic Retinal Prosthesis

TOP is the Neural Interface Laboratory software page for the MATLAB model associated with:

**Kyungsik Eom, Kyung Min Byun, Sang Beom Jun, Sung June Kim, and Jonghwan Lee.**  
“Theoretical Study on Gold-Nanorod-Enhanced Near-Infrared Neural Stimulation.”  
*Biophysical Journal* 115(8), 1481–1497 (2018).  
DOI: https://doi.org/10.1016/j.bpj.2018.09.004

## Model workflow
NIR absorption by gold nanorods → local heating → TRPV1 and heat-induced capacitive current → membrane-potential response with a modified Hodgkin–Huxley model.
